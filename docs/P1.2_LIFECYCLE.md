# P1.2 Content Lifecycle

**Date:** 2026-09-14  
**Code:** `browser-core/src/lifecycle.rs` + `ContentProcessManager`

## State machine

```
Starting
   │ HelloOk
   ▼
Ready
   │ MarkRunning
   ▼
Running ←──────────────┐
   │ Suspend           │ Resume
   ▼                   │
Suspending             │
   │ SuspendedAck      │
   ▼                   │
Suspended ─────────────┘

Running / Ready / … 
   │ Crash
   ▼
Dead
   ├─ RestartScheduled → Restarting → Spawned → Starting
   └─ CrashLoop → CrashLoopLocked
                      │ RestartBegin (user Retry)
                      └→ Restarting

Any active state
   │ Shutdown
   ▼
Shutdown  (terminal — no further transitions)
```

## Rules

| Rule | Behavior |
|------|----------|
| Invalid transition | `Err(TransitionError)` — explicit |
| IPC allowed | Ready, Running, Suspending, Suspended |
| Crash loop | `CrashLoopLocked` — no automatic respawn |
| Browser shutdown | `shutting_down=true` → no spawn/respawn; `RestartDecision::Gone` |

`lifecycle::tests::*` — happy path, crash/restart/lockout, invalid from Shutdown, shutdown during Restarting.
