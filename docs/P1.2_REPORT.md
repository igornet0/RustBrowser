# P1.2 COMPLETE — Browser Hardening & Boundary Preparation

**Date:** 2026-09-14

## Boundary

Browser = privileged coordinator; Content = untrusted renderer; IPC = explicit fail-closed boundary.  
Audit: `docs/P1.2_BOUNDARY_AUDIT.md`. Production Browser still does not own Servo.

## IPC

- `PROTOCOL_VERSION = 3`
- Limits: `MAX_MESSAGE_SIZE` 16 MiB, frame dim/byte caps, URL/string caps
- Version mismatch → reject
- Oversized message/frame / invalid dims / rgba length → reject/drop
- Envelope `generation` + `sequence`; stale generation/duplicates dropped
- Single protocol (`browser-ipc`) — no second IPC stack
- Seam: `SetNetworkRoute` (non-secret)

## Lifecycle

Formal machine in `lifecycle.rs` — Starting→Ready→Running→…→Dead/Restarting/CrashLoopLocked/Shutdown.  
Invalid transitions tested. Docs: `docs/P1.2_LIFECYCLE.md`.

## Crash recovery

Death/hang → restart with new generation; crash-loop lockout; **`shutting_down` blocks respawn**; stale pid/socket discarded. Kill integration test passes.

## Keyboard

`ipc_keymap`: letters/digits, Enter/Esc/Tab/Backspace/Delete/arrows/Home/End/Page*, F1–F12, Shift/Ctrl/Alt/Meta (Cmd). Unit tests pass.

## Frame benchmark

| Res | Result |
|-----|--------|
| 800×600 | ~3.7 fps, ~271 ms avg RTT (JSON RGBA) |
| 1280×720 | ~2.1 fps, ~486 ms avg |
| 1920×1080 | **blocked** — JSON ~32 MiB > 16 MiB limit |

JSON expands ~4×. **Rendering transport is the main measured bottleneck.**

## Resource limits
