# P1.1 Report — Complete Servo Content Process Isolation

**Date:** 2026-09-14  
**Status:** P1.1 COMPLETE (architecture). Sandbox / site isolation still out of scope.

## Architecture (default)

```
Browser Process
 ├── UI / egui
 ├── Browser state / tabs / session
 ├── Content Manager
 ├── IPC client
 └── UiSurface + CPU frame presentation
          │
          │ Unix IPC (PROTOCOL_VERSION = 2)
          ▼
Content Process
 └── Servo + SoftwareRenderingContext + WebViews
```

## Servo ownership

| Component | Owner |
|-----------|--------|
| Servo runtime / WebView | **Content only** |
| SoftwareRenderingContext | **Content only** |
| Tab/session browser state | Browser |
| Frame presentation (egui texture) | Browser |
| Input / navigation | Browser → IPC → Content → Servo |

Production default **does not** construct `ServoEngine` in the Browser process.  
`RUST_BROWSER_CONTENT=inprocess` is legacy/debug only and prints a WARNING.

## IPC

Extended existing `browser-ipc` (no second protocol): CreateTab, Navigate, Reload, GoBack, GoForward, Resize, SetViewport, Input, Suspend/Resume, CloseTab, Frame, nav/load events, Ready, Heartbeat, Crash/Error.

## Crash recovery

Unchanged P1 manager path: death detection → backoff restart → tab restore from Browser state; hang via heartbeat timeout; crash-loop lockout.

## Security

- Content: `profile/content/` only; no password DB; no Keychain
- Browser: secrets / credentials / session
- **Sandbox: NOT IMPLEMENTED**

## Remaining gaps

1. OS sandbox — not started  
2. Site isolation — seam only  
3. Frame transport is full RGBA (measure before optimizing)  
4. Proxy route application inside Content not fully wired  
5. Keyboard IPC is best-effort NamedKey mapping  

## P2 Network Core

**NOT READY** to start automatically — architecture gate for P1.1 is met, but Network Service design/work has not begun. Start P2 only when explicitly requested.
