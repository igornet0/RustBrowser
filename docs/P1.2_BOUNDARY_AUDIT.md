# P1.2 Boundary Audit — Browser ↔ Content

**Date:** 2026-09-14  
**Rule:** claims from repository code only. Process separation ≠ OS sandbox.

## Summary

| Finding | Verdict |
|---------|---------|
| Production Browser owns Servo? | **No** — `PageBackend::Isolated` / Content `content_runtime.rs` |
| Secrets in Content env/args? | **No passwords/Keychain paths** — spawn uses `env_clear` + PATH/HOME/RUST_LOG/(DYLD) + `--content-storage` under `profile/content/` |
| IPC carries secrets? | **No** — nav/input/frames/strings only (`browser-ipc`) |
| Content→Browser privileged ops? | **Limited** — Content may only send protocol events; cannot call Browser APIs |
| OS sandbox? | **NOT IMPLEMENTED** |

## Boundary table

| Boundary | Current behavior | Risk | Required action | Status |
|----------|------------------|------|-----------------|--------|
| Browser → Content | Commands via Unix IPC (`CreateTab`, `Navigate`, `Input`, …). No Servo handles. | Oversized/malformed payloads could DoS Content | Fail-closed validation + size limits | **P1.2** |
| Content → Browser | Events/frames via IPC only; Browser applies to UI/state | Stale frames after restart; oversized RGBA | `generation` + sequence + frame validation | **P1.2** |
| Filesystem | Content storage = `content_dir/<process_id>`; Browser secrets under profile storage/Keychain | Misconfigured root could widen access | Keep content dir distinct; document; tests | **Partial** (intent YES; OS confinement NO) |
| Secrets | Password DB / Keychain only in Browser (`browser-profile`); Content spawn does not pass secret paths | Accidental future IPC fields | Forbid secret fields in protocol; audit | **Keep / harden docs** |
| IPC | Framed JSON, `PROTOCOL_VERSION`, request ids; soft size cap 64 MiB | Weak payload semantic checks; no generation | Limits, validate frame dims, reject bad version | **P1.2** |
| Rendering | Content `SoftwareRenderingContext` → RGBA → IPC → egui texture | Bandwidth/CPU cost; unvalidated dims | Measure then decide; validate before accept | **Measure in P1.2** |
| Lifecycle | Manager states Starting/Ready/Crashed/Restarting/Dead | Informal transitions | Formal state machine + invalid transition tests | **P1.2** |
| Input | egui → Browser → IPC `InputEventMsg` → Servo | Incomplete NamedKey map | Complete mapping + tests | **P1.2** |

## Code evidence

| Check | Location |
|-------|----------|
| Content spawn env | `process_manager.rs` `spawn_with_id` — `env_clear`, no password DB |
| Isolated backend | `browser-ui/src/page_backend.rs` `PageBackend::Isolated` |
| Legacy Servo only | `start_legacy` + `RUST_BROWSER_CONTENT=inprocess` |
| Frame path | `content_runtime.rs` `capture_frame` → `ContentToBrowser::Frame` → `paint_page_egui` |
| Protocol | `browser-ipc/src/protocol.rs` |

## Explicit non-claims

- Not an OS sandbox (Seatbelt / AppContainer / seccomp).
- Not site isolation.
- Not network isolation.
- Compromised Content can still abuse its own process (CPU, its storage dir, network via Servo) until sandbox exists.
