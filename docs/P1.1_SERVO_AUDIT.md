# P1.1 Servo Ownership Audit

**Date:** 2026-09-14  
**Rule:** based on repository search only — no assumptions.  
**Update:** post-implementation ownership (P1.1).

## Ownership table

| Component | Current owner (pre-P1.1) | Required owner | Action | Post-P1.1 |
|-----------|--------------------------|----------------|--------|-----------|
| Servo runtime | Browser (`ServoEngine`) **and** Content | Content | MOVE | Content (`content_runtime.rs`) |
| WebView | Browser + Content | Content | MOVE | Content |
| Rendering context (page) | Browser Offscreen + Content Software | Content Software | MOVE | Content `SoftwareRenderingContext` |
| Window GL for egui | Browser | Browser `UiSurface` | KEEP | Browser (`ui_surface.rs`) |
| Navigation | Browser → `engine.navigate` (+ mirror IPC) | Browser → IPC → Content | REFACTOR | `PageBackend::Isolated` → IPC |
| Tab / session state | Browser | Browser | KEEP | Browser |
| Frame presentation | Browser GL blit | Browser egui CPU texture from IPC Frame | REFACTOR | `paint_page_egui` |
| Input | Browser → `engine.handle_window_event` | Browser → IPC Input → Content | REFACTOR | IPC `InputEventMsg` |
| Crash recovery | Dual | Content death → Manager restart | REFACTOR | `RemoteContentSession` |
| `RUST_BROWSER_CONTENT=inprocess` | Disables remote | Legacy/debug + warning | ISOLATE | `PageBackend::Legacy` only |

## Code map (verified)

| Question | Location |
|----------|----------|
| Where is ServoEngine created? | `page_backend.rs` → `start_legacy` only (`RUST_BROWSER_CONTENT=inprocess`) |
| Where is WebView created (production)? | `browser-engine/src/content_runtime.rs` |
| Browser direct Servo calls (production)? | **None** — `PageBackend::Isolated` |
| UI frame path | `chrome.rs` → `paint_page_egui` / IPC `Frame` |
| Navigation | `controller` → `PageBackend::navigate` → IPC |
| Input | `app.rs` → `PageBackend::handle_window_event` → IPC |
| Rendering context (page) | Content `SoftwareRenderingContext` |
| Browser structures holding Servo | Only `PageBackend::Legacy(ServoEngine)` |

## IPC (extended, not duplicated)

Browser→Content: Hello, CreateTab, Navigate, Reload, GoBack, GoForward, Stop, CloseTab, FocusTab, SuspendTab, ResumeTab, Resize, SetViewport, Input, RequestFrame, Heartbeat, Shutdown  

Content→Browser: HelloAck, Ready, ProtocolMismatch, NavigationStarted, NavigationFinished, UrlChanged, TitleChanged, LoadStatusChanged, LoadProgress, HistoryChanged, Frame, ConsoleMessage, TabCrashed, Error, HeartbeatAck, ShutdownAck  

## Non-goals (still)

Sandbox, site isolation, VPN, network rewrite.
